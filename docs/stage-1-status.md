## Подготовленные изменения

- Единый production origin по умолчанию и проверка конфигурации, запрещающая production-сборку с localhost/HTTP.
- Абсолютные URL canonical, Open Graph, Twitter image, WebSite, Organization и BreadcrumbList через общий origin. Тип Organization сохранён.
- Sitemap и robots используют тот же origin; неактуальная директива Host удалена.
- Отдельная команда статического экспорта для Nginx с существующим same-origin API; вариант Pages с отдельным Worker сохранён.
- Проверка фактического статического экспорта: страницы, canonical, OG/Twitter, JSON-LD, sitemap, robots, 404 и размер OG image.
- Безопасная остановка при оставшемся каталоге API от прерванной сборки.
- Минимальный Nginx-фрагмент для www и инструкция обновления/отката.
